# The Fuel Station

Static restaurant and food-ordering frontend with menu items, food galleries, customer reviews, and an order form. The repository contains HTML, CSS, JavaScript, and images, without a payment or order-processing backend.

## Getting started

Run `python -m http.server 8000` here and open `http://localhost:8000/`.
